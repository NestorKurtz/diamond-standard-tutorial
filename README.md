# diamond-standard-tutorial

Complete guide to EIP-2535 Diamond Standard - with a fun terminal experience!

## Terminal Fun Feature

An interactive CLI tool that teaches the Diamond Standard (EIP-2535) directly in your terminal, complete with ASCII art, colors, quizzes, and diamond jokes.

### Features

- **5 interactive lessons** covering the Diamond Standard from basics to advanced
- **Quiz mode** with 5 questions to test your knowledge
- **Diamond jokes** to keep you entertained while learning
- **ASCII art show** with animated diamonds
- **Cheatsheet** for quick reference

### Usage

```bash
# Start the interactive tutorial
npm start

# Jump straight to the quiz
npm run quiz

# Quick joke
node src/cli.js --joke

# Test that everything works
npm test
```

### What you'll learn

1. What is the Diamond Standard (EIP-2535)?
2. The three core components (Diamond, DiamondCut, DiamondLoupe)
3. How `delegatecall` works
4. Diamond Storage Pattern
5. DiamondCut - upgrading your diamond
